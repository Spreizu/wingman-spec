# Skill origins

These skills are maintained in this repository. They were forked from MIT-licensed upstreams
and rewritten for the wingman-spec apply loop (the CLI, not the agent, accepts each task).
They are installed as `wingman-*` so they do not collide with a user's own copy of the upstream.
